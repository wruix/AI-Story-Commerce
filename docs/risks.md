# AI Story Commerce — 风险与限制清单

## 1. 环境与技术风险

| 风险 | 说明 | 应对措施 |
|------|------|---------|
| Python 版本差异 | 技术基线要求 Python 3.12，实际环境为 Python 3.11 | 首期可用 Python 3.11，后续环境具备条件后升级至 3.12 |
| 磁盘空间有限 | D 盘剩余约 9.66 GB，视频素材和成片可能占用较多空间 | 定期清理中间素材，控制素材体积，必要时迁移至外部存储 |
| SQLite 并发限制 | 首期采用 SQLite，不适合高并发写入 | 首期为单用户本地开发，后续迁移 PostgreSQL |
| 视频生成平台未打通 | 第一版不要求打通所有视频生成平台API | 素材手动上传，生产管理系统管理外部生成任务 |
| FFmpeg 依赖 | 需要本地安装 FFmpeg | 检查环境中是否已安装，未安装则下载便携版 |

## 2. 合规与法律风险

| 风险 | 说明 | 应对措施 |
|------|------|---------|
| AI生成合成内容标识 | 中国大陆《人工智能生成合成内容标识办法》2025年9月1日起施行 | 系统设置合规审核为发布前硬门槛，记录AI标识状态 |
| 广告法合规 | 《互联网广告管理办法》适用于互联网媒介商业广告 | 设立广告审核Agent，检查商品真实性、功效宣称、价格 |
| 虚构体验冒充 | 不得冒充真实消费者体验 | 审核时明确标注内容为AI生成或剧情演绎 |
| 人物肖像授权 | 虚拟人物“阿强”形象需合法授权 | 使用自有生成素材，保留生成记录和授权证明 |
| 声音克隆授权 | 必须取得相应授权 | 首期使用合法授权的合成音频，留存授权记录 |
| 音乐商业使用 | 需有商业使用许可 | 使用无版权或已获授权的音乐素材 |
| 商标侵权 | 不得侵犯他人商标权 | 剧情中避免使用未授权品牌商标 |

## 3. 商业与运营风险

| 风险 | 说明 | 应对措施 |
|------|------|---------|
| 无付费客户 | 30天内可能未获得真实付费订单 | A线优先商业生产，D7前拿出样片，积极开发商家 |
| 内容同质化 | AI生成内容可能重复套路 | 剧情创意Agent每个商品生成10个不同故事，避免套路 |
| 人物一致性 | 虚拟人物在不同视频中形象不一致 | 建立人物圣经和固定参考资产，所有生成以固定资产为输入 |
| 技术过度投入 | 软件开发成为项目主角，忽视商业验证 | 双线推进，A线商业生产优先级最高，B线软件开发围绕A线需求 |

## 4. 操作限制（HNS执行约束）

- 不得修改其他AI项目的代码
- 不得操作用户其他项目的数据库
- 不得安装系统级服务和虚拟化环境
- 不得修改 Windows 安全策略
- 不得获取或保存商家账号密码
- 不得使用真实商家账号自动发布
- 不得自动投放真实广告或产生费用
- 不得擅自购买 AI API 额度
- 不得删除生产素材和历史证据
- 不得未经审核发布商业广告
- G1–G7 需分别获得阶段授权，不得自行扩大授权
- 如遇系统环境问题、依赖冲突、数据损坏风险或需要外部服务付费，必须立即停止相关操作并报告

## 5. 数据安全限制

- 所有AI生成内容必须保留原始输入和输出
- 所有剧本必须支持版本管理，不能覆盖历史版本
- 不得用虚构的广告效果数据作为真实经营数据
- 不得将内部测试数据伪装成客户案例
- 发布记录必须保留版本、平台和发布时间
