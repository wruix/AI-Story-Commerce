# AI Story Commerce

AI剧情营销与虚拟人商业化系统

> 让故事成为广告，让人物成为IP，让AI成为生产力。

## 项目身份

- **项目名称**：AI Story Commerce
- **项目定位**：AI剧情营销与虚拟人商业化系统
- **项目类型**：AI内容商业化项目
- **首发市场**：中国大陆
- **首发平台**：抖音
- **首期人物**：一个核心虚拟人物，暂定阿强
- **开发工具**：DeepSeek HNS
- **开发模式**：本地开发，云端部署暂缓
- **首期周期**：30天（商业验证）

## 商业战略

先做AI剧情广告服务公司，再发展数字人IP公司，最后将内部生产能力产品化为SaaS。

三条业务线：
- **A线：AI剧情广告服务** — 给商家提供剧情创意、广告剧本、AI视频和成片交付（优先级最高，第一阶段重点）
- **B线：虚拟人物IP运营** — 建立核心人物“阿强”，持续发布短视频和商业内容
- **C线：AI Story Commerce软件平台** — 内部生产系统，未来开放为SaaS

## 技术基线

| 模块 | 技术选型 | 说明 |
|------|---------|------|
| 前端 | Next.js 16 + React 19 + TypeScript 5.9 | 管理界面 |
| 后端 | FastAPI + Python 3.11（首期） | REST API |
| ORM | SQLAlchemy | 数据访问 |
| 迁移 | Alembic | 数据库版本管理 |
| 数据库 | SQLite（首期） | 保留未来迁移 PostgreSQL 能力 |
| 文件 | 本地文件存储 | 统一素材元数据 + SHA256 校验 |
| 视频处理 | FFmpeg | 视频后期 |
| 测试 | Pytest + 前端自动化测试 | API集成测试 |
| 版本管理 | Git | 变更可追溯 |

## 合规提醒

中国大陆已实施《人工智能生成合成内容标识办法》（2025年9月1日起施行）。系统必须把合规审核设为发布前的硬门槛，包括AI生成声明、商品真实性、虚构体验禁止、人物肖像授权、声音克隆授权、音乐商业使用许可、商标不侵权、广告内容合规、发布记录留存。

首期不主动承接医疗功效、金融投资、保健功效等高合规风险领域。
